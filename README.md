# 基于 AI Agent 授权的 Web 漏洞自动检测与复核平台

> AI 原生软件工程实践课程项目 · Python 实现

## 项目简介

本平台对**已授权目标**自动执行 Web 漏洞检测，产出漏洞候选后由 **AI Agent** 决策、从白名单攻击函数库中挑选"验证型模拟攻击"函数完成复核，最终经人工签署形成可追溯、可追责的结论。

核心闭环：

```
目标输入 → 检测引擎 → AI Agent 决策 → 授权控制分级放行 → 模拟攻击执行 → 证据记录 → 复核闭环 → 报告/界面
```

**关键原则**：

- 仅对授权目标检测与模拟攻击；
- 所有攻击为**验证型、可回滚**，不做真实破坏；
- 人对最终结论承担不可推卸的责任，AI 仅作决策与审查辅助；
- 同一结论可通过 Web 界面、命令行、API 三条路径独立复现。

## 核心特色

1. **检测—决策—攻击—复核四段闭环**：每段留痕，形成完整证据链。
2. **AI Agent 授权决策**：分析漏洞候选，从独立注册的攻击函数库中挑选匹配函数并给出选择理由。
3. **按可逆性分级授权**：低危自动执行、中高危人工确认，每次放行均记录审批证据。
4. **证据分层**：自述 ClaimOnly → 静态 Static → 观察 Observed → 复现 Reproduced；对外结论至少达到"观察"级，关键结论要求"复现"级。
5. **高内聚低耦合**：攻击函数白名单注册、可插拔扩展，新增漏洞只需新增"检测器 + 攻击函数"单元。

## 架构分层

| 模块 | 职责 |
|---|---|
| Web 界面层 | 目标配置、审批、可视化、证据查看、报告导出 |
| Agent 编排层 | 分析候选、决策攻击函数、自检复核 |
| 授权控制层 | 目标注册、可逆性分级、审批门禁 |
| 检测引擎 | 按类型调度检测器，产出漏洞候选 |
| 攻击执行器 | 调度白名单攻击函数执行验证型攻击 |
| 攻击函数库 | 各漏洞对应的模拟攻击函数（可插拔） |
| 证据层 | 记录请求/响应/调用/审批证据 |
| 报告层 | 生成报告与 TP/FP/FN 指标统计 |

## 功能需求

| 编号 | 需求项 | 说明 |
|---|---|---|
| F1 | 目标输入 | 界面或命令行接受单个 URL/请求模板，目标须经授权注册 |
| F2 | 漏洞检测 | 注入、目录/敏感文件、越权、配置类漏洞检测与判定 |
| F3 | Agent 决策 | AI Agent 分析候选，挑选模拟攻击函数并给出理由 |
| F4 | 授权控制 | 按可逆性分级放行：低危自动、中高危人工确认 |
| F5 | 模拟攻击 | 调用白名单攻击函数执行验证型攻击，采集响应证据 |
| F6 | 复核闭环 | Agent 自检 + 证据回放，人工最终签署 |
| F7 | 界面操作 | Web 界面配置目标、查看候选、审批攻击、查看结果 |
| F8 | 结果可视化 | 表格、图表（漏洞占比、严重度分布）与交互筛选 |
| F9 | 证据与报告 | 记录请求/响应/调用证据，导出 JSON/Markdown/HTML 报告 |
| F10 | 指标统计 | 统计 TP/FP/FN/TN，形成覆盖度与准确率指标 |

## 授权分级

| 级别 | 风险/可逆性 | 放行方式 | 适用示例 |
|---|---|---|---|
| 低危 | 可逆、无副作用 | AI Agent 自动执行 | 参数注入试探、响应头缺失验证 |
| 中危 | 可能影响少量数据 | 人工在界面确认后执行 | 越权访问验证、敏感文件读取试探 |
| 高危 | 不可逆或高风险 | 人工逐条确认并记录理由 | 涉及写操作、破坏性 payload |

> ⚠️ 任何涉及数据篡改、getShell 或不可逆写操作的请求一律视为越界，不纳入攻击函数库。

## 快速开始

### 环境要求

- Python 3.10+
- 依赖：见 `requirements.txt`

### 安装

```bash
git clone <repo-url>
cd <repo-dir>
pip install -r requirements.txt
```

### 启动方式

**1. Web 界面**

```bash
python -m app.web
# 浏览器打开 http://localhost:8000
```

**2. 命令行**

```bash
python -m app.cli scan --target http://your-authorized-target.com
```

**3. Python API**

```python
from app import Scanner

scanner = Scanner(target="http://your-authorized-target.com")
result = scanner.run()
print(result.summary())
```

> 三种入口对同一输入产出一致结论，互为复现证据。

## 指标口径

| 指标 | 含义 |
|---|---|
| TP | 确实存在漏洞，被正确检出并经模拟攻击确认 |
| FP | 不存在漏洞但被误报 |
| FN | 存在漏洞但未被检出 |
| TN | 不存在漏洞且被正确判为非漏洞 |
| INCONCLUSIVE | 证据不足，如实标注，不强行归类 |

## 验收标准

- **可运行**：干净环境按文档可启动，无手工修补；
- **可复现**：同一输入在同一版本下结果一致；
- **可判定**：每条结论落到 PASS / FAIL / INSUFFICIENT_EVIDENCE / NOT_APPLICABLE；
- **授权合规**：每次模拟攻击均有授权记录与分级审批证据；
- **复核闭环**：每条结论均有 Agent 自检记录与人工签署；
- **可追溯**：可回溯到原始请求/响应/攻击函数调用证据；
- **可回滚**：版本变更可回退，历史结果与证据可恢复。

## 安全与合规声明

本平台**仅用于对已授权目标的安全测试**。使用前必须确认：

1. 目标已获得书面授权；
2. 模拟攻击为验证型、可回滚；
3. 不在生产环境或未授权系统上运行。

越权使用造成的一切后果由使用者自行承担。
