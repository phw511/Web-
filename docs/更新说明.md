### 第二次更新：离线模拟 + 结果可视化与文本导出（`2c4a754`）
| 文件 | 说明 |
|---|---|
| `webvuln/sim/mock_transport.py`（新增） | 离线预置响应传输（**不触网**，非真实接入） |
| `webvuln/sim/runner.py`（新增） | 注册模拟靶标，跑通真实「检测→决策→授权→攻击→结论→证据」闭环 |
| `webvuln/sim/viz.py`（新增） | 单文件 HTML 可视化（内联 SVG 类型分布条形图 + 结论环形图 + 明细表），及 .txt/.md/.json 导出 |
| `webvuln/sim/__init__.py`（新增） | 模拟演示包 |
| `webvuln/cli.py` | 新增 `sim-demo` 子命令 |

**设计要点**：模拟只替换最底层 `Transport` 为 MockTransport，检测器 / RuleAgent / Pipeline / 授权 / 证据 / 报告全部复用真实实现，因此模拟口径与真实口径一致。

## 运行方式

```powershell
# 1. 安装依赖（pydantic / requests / uvicorn 按需）
pip install pydantic requests

# 2. 运行离线模拟 + 可视化 + 文本导出
python -m webvuln.cli sim-demo --out ./sim_out
```

执行后 `sim_out/` 下生成：
- `report.html` —— 可视化报告（指标卡、类型分布条形图、结论环形图、明细表）
- `report.txt` / `report.md` —— 文本 / Markdown 导出
- `report.json` —— 结构化结果

## 示例输出
`示例输出/` 目录内是本工具一次模拟运行的样例产物（SQLi + XSS 均 CONFIRMED，TP=2 / FP=0）。
