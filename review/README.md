# review/ — 互评、变更记录与签署

> 本目录存放"人"的活动记录：谁评审了什么、谁签署了哪条结论、改了什么。
> 与 `eval/`（机器可断言的证据）分工：这里放解释性文档，`eval/` 放原始事实。

## 1. 评审记录模板

```markdown
## 评审 YYYY-MM-DD · 评审人 <name> · 对象 <版本/tag>

| # | 检查项 | 结论 | 证据/位置 |
|---|---|---|---|
| 1 | 需求与实现一致（brief ↔ 代码） | 通过/不通过 | … |
| 2 | 规约未漂移（contracts/behavior） | … | … |
| 3 | 未授权目标零发包 | … | test_egress.py |
| 4 | 预算四项有强制点 | … | test_budget.py |
| 5 | 证据链可独立校验 | … | chain.jsonl + manifest |
| 6 | 文档数字可溯源 | … | eval/evidence-*.md |

**本次发现的问题**：
1. …（严重度 / 影响 / 建议）
**结论**：通过 / 有条件通过（列条件） / 不通过
```
